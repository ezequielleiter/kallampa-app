Cifra clave con etiqueta y nota; KpiGrid las reparte y envuelve en anchos chicos.

```jsx
<KpiGrid items={[
  { label: 'Peso cosechado', value: '4,00 kg', note: '2 oleadas' },
  { label: 'Eficiencia biológica', value: '80,0 %', note: 'sobre 5,00 kg de sustrato' },
  { label: 'Costo por kg', value: '$ 2.290' },
]} />
```

Solo cifras que el usuario usa para decidir; sin métricas decorativas.
