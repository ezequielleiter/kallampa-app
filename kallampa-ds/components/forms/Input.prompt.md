Campo de texto de una línea sobre la clase .input de Nocturne, con prefijo/sufijo de unidad y estado de error.

```jsx
<Input placeholder="nombre@correo.com" type="email" />
<Input inputMode="decimal" suffix="kg" placeholder="0,00" />
<Input prefix="$" inputMode="decimal" />
<Input type="date" defaultValue="2026-09-25" />
```

Números en formato es-AR (coma decimal). Las fechas usan color-scheme dark automáticamente.
