```jsx
<Logo />                         {/* sidebar */}
<Logo size={28} animated />      {/* header de landing */}
<Logo size={96} wordmark={false} />
```

El wordmark siempre va en minúsculas, Inter 500. No recolorear el micelio: siempre --color-accent.
