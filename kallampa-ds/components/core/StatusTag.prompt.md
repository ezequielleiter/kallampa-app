Etiqueta de estado de dominio (frascos, placas, recipientes, micelio líquido, lotes); mapea cada estado a su tono.

```jsx
<StatusTag status="Colonizado" />
<StatusTag status="Incubando" />
<StatusTag status="Contaminado" />
<StatusTag status="Descartado" />
```

Tonos: en progreso → outline; activo/listo → accent; terminado → neutral; Descartado → neutral tachado; Contaminado → danger.
