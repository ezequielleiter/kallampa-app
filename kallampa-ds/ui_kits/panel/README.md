# UI kit · Panel Kallampa

Recreación click-through del panel de producción construida solo con los componentes de `components/`.

- `index.html` — shell (Sidebar + Topbar + Toast) y navegación entre vistas.
- `LotesScreen.jsx` — lista de lotes con filtro y filas clicables.
- `LoteScreen.jsx` — detalle de lote: etapas, KPIs, frascos con StateSelect, incubación con Menu, cosecha con Dialog de oleada, Drawer de Nueva incubación, Pendientes y Costos.

La fuente de verdad visual y de comportamiento completo es el prototipo `Kallampa Panel.dc.html` en la raíz del proyecto (incluye Nuevo lote, edición de oleadas y la sección Micelio).
